### Integrations

#### Integration
- **Description:** PdfiumSignatureVerifier uses reflection to inspect PdfiumInterop class and extract all DllImport declarations for validation
- **Frontend Component:** PdfiumSignatureVerifier
- **Backend Endpoint:** System.Reflection APIs
- **Data Flow:** Verifier → Reflection (GetMethods) → Extract DllImport attributes → Compare with DLL exports from DllAnalyzer

#### Integration
- **Description:** PdfiumSignatureVerifier integrates with DllAnalyzer to get actual DLL exports and compare against P/Invoke declarations
- **Frontend Component:** PdfiumSignatureVerifier
- **Backend Endpoint:** IDllAnalyzer.AnalyzeAsync / GetExportedFunctions
- **Data Flow:** Verifier calls AnalyzeAsync → DllAnalyzer parses PE file → Returns DllInfo and exports → Verifier compares with P/Invoke declarations

#### Integration
- **Description:** Test suite uses NSubstitute to mock IDllAnalyzer for unit testing without requiring actual PDFium DLL
- **Frontend Component:** PdfiumSignatureVerifierTests
- **Backend Endpoint:** IDllAnalyzer (mocked)
- **Data Flow:** Test setup → Create mock DllAnalyzer → Configure mock responses → Execute verifier → Assert results

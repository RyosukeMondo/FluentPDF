### Integrations

#### Integration
- **Description:** ThemeService integrates with Avalonia's Application.ActualThemeVariant and ActualThemeVariantChanged event for automatic system theme detection. Uses BehaviorSubject for reactive theme stream, logs all changes with Serilog correlation IDs.
- **Frontend Component:** ThemeService
- **Backend Endpoint:** Avalonia Application Theme API
- **Data Flow:** System theme change → Avalonia ActualThemeVariantChanged event → Observable.FromEventPattern → OnSystemThemeChanged → BehaviorSubject.OnNext → Subscribers notified → Application.RequestedThemeVariant updated → UI re-renders

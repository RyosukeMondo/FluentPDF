#### Integration
- **Description:** PdfViewerViewModel integrates with IAnimationService for page navigation animations with rapid cancellation support
- **Frontend Component:** PdfViewerViewModel
- **Backend Endpoint:** IAnimationService.AnimatePageTransitionAsync
- **Data Flow:** User navigates → GoToNextPage/GoToPreviousPage/GoToPage command → Cancel previous animation CTS → Create new CTS → Call AnimatePageTransitionAsync (non-blocking) → Render page → Animation completes or cancels on next navigation

#### Integration
- **Description:** AnimationService uses WinUI 3 Composition API for GPU-accelerated animations with Windows accessibility integration
- **Frontend Component:** AnimationService
- **Backend Endpoint:** Windows.UI.ViewManagement.UISettings, Microsoft.UI.Composition
- **Data Flow:** Service initializes → Detect UISettings.AnimationsEnabled → Animation requested → Get ElementCompositionPreview.GetElementVisual → Create CompositionAnimation → Apply to visual → Wait for duration or cancellation → Complete

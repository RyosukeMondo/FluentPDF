### Integrations

#### Integration
- **Description:** ThemeService subscribes to Avalonia's Application.ActualThemeVariantChanged event using System.Reactive Observable.FromEventPattern to detect OS theme changes and automatically emit updates via BehaviorSubject<ThemeVariant> stream
- **Frontend Component:** Any ViewModel or View
- **Backend Endpoint:** ThemeService.ObserveThemeChanges()
- **Data Flow:** OS theme change -> ActualThemeVariantChanged event -> Observable.FromEventPattern -> OnSystemThemeChanged handler -> BehaviorSubject.OnNext -> Subscribers notified -> UI updates reactively

#### Integration
- **Description:** ThemeService registered as singleton in Microsoft.Extensions.DependencyInjection container for constructor injection into ViewModels
- **Frontend Component:** ViewModels (MainViewModel, SettingsViewModel, etc.)
- **Backend Endpoint:** IServiceCollection.AddSingleton<IThemeService, ThemeService>()
- **Data Flow:** App.axaml.cs ConfigureServices -> DI registration -> Constructor injection -> ViewModel subscribes to ObserveThemeChanges() -> Reactive UI updates

#### Integration
- **Description:** Windows accent color detection via Registry for UI customization (requires Windows platform)
- **Frontend Component:** Theme-aware UI components
- **Backend Endpoint:** ThemeService.GetSystemAccentColor()
- **Data Flow:** GetSystemAccentColor() -> Registry read (HKCU\Software\Microsoft\Windows\DWM\AccentColor) -> AABBGGRR to ARGB conversion -> System.Drawing.Color -> Result<Color> returned
